# Noisemaker Curated

Noisemaker DSL programs by Alex Ayars and Jess Hewitt, selected from Noiseblaster and Visualize.

Content cutoff: **2026-10-13**. This collection will be updated over time.

## Contents

- `programs.json` lists the programs, authors, source metadata, file paths, and SHA-256 hashes.
- `programs/<code>/program.dsl` contains each program.
- `programs/<code>/metadata.json` contains its metadata.
- Some programs include `effects.json` with their custom shader definitions.
